CV Generator

A simple CV generator built with React. It allows users to enter their personal information, education, work experience and generate a clean CV from that information.

This project was built as part of my journey learning React and helped me practice working with components, state, props forms, and conditional rendering.

Features
Add personal information
Add and edit education details
Add and edit work experience
Preview the CV while editing
Generate a clean CV layout
Edit information without reloading the page
Responsive layout
Built With
React
JavaScript
HTML
CSS
Vite

Conditional rendering
Structuring a React project

The main goal of this project was not just to make a CV generator, but to get more practice building something with React from scratch.

Getting Started

To run the project locally, clone the repository:

git clone <git@github.com:mawais09701-bot/cv-generator.git>

Move into the project directory:

cd <cv-generator>

Install the dependencies:

npm install

Start the development server:

npm run dev

Then open the local URL shown in the terminal.

Project Structure

The project is organized into React components, with different parts of the CV and form handled separately.

For example:

src/
├── components/
├── App.jsx
├── main.jsx
└── styles/

The exact structure may vary depending on the component organization used in the project.
